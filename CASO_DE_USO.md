Categorização de perguntas

Ator: Usuário do fórum

Pré-condições:
- O usuário deve estar na área de cadastro de perguntas.
- O sistema deve possuir categorias disponíveis para seleção.

Fluxo Principal:
1. O usuário acessa a opção para cadastrar uma nova pergunta.
2. O sistema apresenta os campos da pergunta e as opções de categoria.
3. O usuário preenche o conteúdo da pergunta.
4. O usuário escolhe a categoria que melhor representa o assunto.
5. O sistema salva a pergunta com a categoria informada.
6. A pergunta passa a ser exibida junto com sua categoria.

Fluxo Alternativo: Tentativa de cadastro sem categoria
4a. O usuário tenta enviar a pergunta sem selecionar uma categoria.
4b. O sistema informa que a categoria precisa ser escolhida.
4c. O usuário seleciona uma categoria e conclui o cadastro.

Pós-condições:
- A pergunta é registrada no sistema.
- A categoria selecionada permanece vinculada à pergunta.
