História 1: Busca de perguntas por palavra-chave

Como usuário do fórum,
Eu quero buscar perguntas por palavra-chave,
Para encontrar conteúdos relacionados a um assunto.

Critérios de Aceitação:
- O sistema deve disponibilizar um campo específico para pesquisa.
- As perguntas exibidas devem ter relação com a palavra digitada pelo usuário.
- Não havendo resultado, o sistema deve informar.
- Os resultados encontrados devem ser mostrados de forma clara ao usuário.

História 2: Categorização de perguntas

Como usuário do fórum,
Eu quero organizar perguntas por categorias,
Para encontrar conteúdos de interesse.

Critérios de Aceitação:
- Toda pergunta cadastrada deve estar associada a uma categoria.
- O usuário deve conseguir escolher a categoria no momento do cadastro.
- A categoria selecionada deve aparecer junto com a pergunta.
- O sistema deve permitir consultar perguntas de uma categoria específica.

História 3: Sistema de votação

Como usuário do fórum,
Eu quero votar nas perguntas com upvote ou downvote,
Para indicar conteúdos relevantes.

Critérios de Aceitação:
- Cada pergunta deve apresentar opções para voto positivo e negativo.
- A quantidade de votos deve ficar visível para o usuário.
- O resultado da votação deve ser atualizado após cada voto.
- Cada usuário deve ter apenas um voto registrado por pergunta.


A busca por palavra-chave ficou como primeira prioridade porque facilita 
encontrar perguntas que já existem no fórum. Depois vem a categorização, que 
ajuda a deixar os conteúdos mais organizados. Por último, ficou o sistema de 
votação, que é importante para destacar perguntas mais relevantes, mas não 
interfere tanto no acesso e na organização das informações.
